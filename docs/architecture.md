# Архітектура AI-агента

**Які проблеми вирішує агент:**
Агент автоматизує рутинні задачі з розгортання проєкту: створює базову структуру C++ застосунку, генерує систему складання CMake, налаштовує тестове середовище GoogleTest та створює CI/CD пайплайн для GitHub Actions без ручного написання коду.

**Які skills він використовує:**
- `project-scaffold`: генерація файлової структури, README та .gitignore.
- `build-and-test`: створення CMakeLists.txt, тестової функції та юніт-тестів.
- `github-actions`: створення ci.yml для перевірки збірки на Windows, Linux та macOS.

**Які commands доступні користувачу:**
- `git-init`: налаштовує .gitignore та перевіряє стан репозиторію.
- `create-project`: запускає project-scaffold.
- `create-build`: запускає build-and-test.
- `create-actions`: запускає github-actions.
- `check`: перевіряє структуру, конфігурацію та складання без зміни коду.
- `init`: оркестратор, що викликає всі вищезазначені команди послідовно.

**Які дані передаються між етапами:**
Мова та назва проєкту передаються від оркестратора до `project-scaffold`. Створена структура каталогів та шляхи до вихідних файлів є базою для кроку `build-and-test`. Результат локального складання проєкту є передумовою для генерації CI workflow у `create-actions`.

**Як оркестратор обробляє помилки:**
Команда `init` перевіряє результати виконання кожної `command`. Якщо якийсь крок завершується невдачею або не проходить валідацію через команду `check`, оркестратор негайно припиняє виконання наступних кроків і повідомляє про помилку, щоб не зламати вже існуючі файли.
