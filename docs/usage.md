# Інструкція з використання (Usage)

## 1. Запуск AI-агента
Щоб запустити процес автоматичної генерації проєкту, відкрийте GitHub Copilot Chat у середовищі розробки та виконайте наступний запит (промпт):

> `@workspace Прочитай маніфест з файлу .github/agents/build-engineer.agent.md. Твоя задача — виконати команду оркестратора з файлу .github/prompts/init.prompt.md, яка послідовно викличе всі інші команди. Згенеруй усі необхідні файли згідно з описаними навичками.`

## 2. Локальна перевірка проєкту
Після того, як агент згенерує `CMakeLists.txt` та вихідний код, виконайте наступні команди в терміналі (Linux/macOS) для складання та тестування:

```bash
# Створення та перехід у директорію збірки
mkdir -p build
cd build

# Конфігурація CMake
cmake ..

# Складання проєкту
make

# Запуск юніт-тестів GoogleTest
ctest --output-on-failure
