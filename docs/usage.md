# Інструкція користувача

## 1. Збірка проєкту

Для збірки проєкту потрібні CMake та компілятор C++17.

У кореневому каталозі проєкту виконайте:

```bash
mkdir build
cd build
cmake ..
cmake --build .
```

Команда `cmake ..` налаштовує систему збірки, а `cmake --build .` компілює
застосунок і тестовий виконуваний файл.

## 2. Запуск

### Linux та macOS

Перебуваючи в каталозі `build`, запустіть:

```bash
./hello
```

### Windows

Для одноконфігураційної збірки запустіть у каталозі `build`:

```bat
hello.exe
```

Якщо використовується Visual Studio або інший багатоконфігураційний генератор,
виконуваний файл Debug розташований у `build/Debug/hello.exe`:

```bat
Debug\hello.exe
```

## 3. Тестування

Після збірки перейдіть до каталогу `build` і запустіть тести через CTest:

```bash
ctest --output-on-failure
```

Параметр `--output-on-failure` виводить детальну інформацію, якщо будь-який
тест завершиться з помилкою.
